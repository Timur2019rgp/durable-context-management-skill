# Routing Examples

- Stable cross-topic interaction preference → user profile candidate.
- Verified reusable release procedure → skill candidate.
- Current server version → dated project/live snapshot.
- Hypothesis about a bug → canonical project store with hypothesis status.
- “We are only discussing this” → no durable writes.
- Provider reports `available` → not proof of working retain/recall.
- Profile rejects a procedure → preserve `ADMIT`, route to a skill or project store.
